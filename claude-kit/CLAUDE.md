# Klara — Flutter app

AI-приложение для финансов, созданное для женщин. iOS и Android, рынки: Испания, далее Латинская Америка. Языки: ES, EN, RU.

## Архитектура

- MVVM по образцу официального Compass app: `lib/ui/<feature>/` (виджеты + Bloc), `lib/data/` (репозитории и сервисы), `lib/domain/` (модели).
- Shared-виджеты и тема — только в `lib/ui/core/ui/` и `lib/ui/core/themes/`.
- Состояние — Bloc / Cubit. Состояния описываются sealed-классами: `Initial / Loading / Success / Failure`.
- Навигация — go_router с типизированными маршрутами. Тип представления (screen / sheet / dialog) задаётся в описании маршрута.
- Источник истины для данных — репозиторий с кэшем. Экран читает репозиторий через Bloc и не делает запросов сам.

## Жёсткие правила

1. Перед созданием виджета найди аналог в `lib/ui/core/ui/`. Если он есть — расширь его опциональным параметром. Новый shared-виджет сразу добавляй в каталог Widgetbook.
2. Никаких магических чисел и HEX-цветов в экранах. Отступы, радиусы, цвета — только токены темы (`ThemeExtension`, `ColorScheme`).
3. Отступы от краёв экрана и safe area задаёт только `AppScaffold`. Экраны не оборачиваются в `SafeArea` сами.
4. Bottom sheet закрывается только свайпом вниз и тапом по фону. Кнопки «Закрыть», «Cancel», «Back» в sheet не добавляются.
5. Каждая анимация появления имеет обратную анимацию скрытия.
6. Все строки — в ARB (gen-l10n). Строковые литералы в виджетах запрещены.
7. После каждого `await` в виджете — проверка `context.mounted`.
8. Повторные нажатия на действия с переходом или запросом блокируются (`bloc_concurrency`: `droppable()`).

## Стек

| Задача | Пакет |
|---|---|
| Состояние | flutter_bloc, bloc_concurrency, hydrated_bloc, bloc_test |
| Навигация | go_router, go_router_builder |
| Bottom sheets | smooth_sheets или wolt_modal_sheet за адаптером `AppSheet` |
| Анимации | flutter_animate |
| Загрузка | skeletonizer |
| Уведомления | toastification за адаптером `AppToast` |
| Документы с сервера | flutter_markdown_plus |
| Каталог компонентов | widgetbook |
| E2E-тесты | patrol |
| Ошибки и мониторинг | sentry_flutter |
| Lint | very_good_analysis + custom_lint |

Сторонний пакет в экранах не используется напрямую — только через адаптер в `lib/ui/core/`. Новые зависимости добавляются только после согласования.

## Проверка результата

Работа считается сделанной, только когда `tool/verify.sh` завершается без ошибок. Hook запускает его автоматически перед завершением задачи.

Минимальная матрица устройств для golden-тестов: iPhone SE (375×667), Android compact (360×640), большой телефон 20:9, планшет в портретной и альбомной ориентации. Светлая и тёмная тема, масштаб шрифта 1.0 и 2.0, локали ES и RU.

## Где что лежит

- Дефекты и кейсы из QA-разбора — скилл `klara-qa`.
- Проверка экрана перед сдачей — скилл `ui-review`.
- Новый экран — скилл `new-screen`.
- Шаблон фича-задания — `.claude/templates/feature.md`.
