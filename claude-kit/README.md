# Claude Kit для Flutter-проекта Klara

Набор настроек Claude Code, который превращает результаты этого QA-разбора в рабочий процесс: агент берёт дефект, находит причину в коде, пишет воспроизводящий тест, исправляет и проверяет результат автоматически.

## Установка

Скопировать содержимое папки `claude-kit/` в корень Flutter-проекта Klara (вместе со скрытой папкой `.claude/`):

```
cp -R claude-kit/. /путь/к/klara-app/
chmod +x /путь/к/klara-app/.claude/hooks/*.sh /путь/к/klara-app/tool/verify.sh
```

Затем открыть проект в Claude Code, выполнить `/mcp` и авторизоваться в Qase и Figma.

Если в проекте уже есть `CLAUDE.md`, нужно объединить его с файлом из набора вручную.

## Что внутри

| Файл | Назначение |
|---|---|
| `CLAUDE.md` | Архитектура, правила и стек проекта. Загружается в каждую сессию |
| `.claude/rules/` | Правила, которые подгружаются только при работе с файлами нужного слоя: UI-кит, состояние, навигация |
| `.claude/skills/klara-qa/` | Работа с дефектами из этого репозитория: порядок, цикл «тест → исправление → проверка», закрытие в Qase |
| `.claude/skills/ui-review/` | Чек-лист проверки экрана, собранный из 54 найденных дефектов |
| `.claude/skills/new-screen/` | Создание нового экрана по стандартам проекта |
| `.claude/templates/feature.md` | Шаблон фича-задания с измеримыми критериями приёмки |
| `.claude/settings.json`, `.claude/hooks/` | Hooks: анализ каждого изменённого `.dart`-файла и полная проверка перед завершением задачи |
| `.mcp.json` | MCP-серверы: Dart/Flutter (анализ, тесты, запущенное приложение), Figma (макеты), Qase (дефекты и кейсы) |
| `tool/verify.sh` | Единая команда проверки: формат, анализ, тесты, golden-тесты |

## Как начать работу

В Claude Code внутри проекта Klara:

```
Возьми в работу дефекты из QA-разбора, начни с системных.
```

Скилл `klara-qa` подхватит запрос сам. Источник данных — этот репозиторий: `defects/defects.md` (дефекты с решениями и ссылками), `test-cases/test-cases.md` (критерии приёмки), `summary.txt` (приоритеты).

## Перед первым запуском

Пути в правилах (`lib/ui/**`, `lib/data/**` и т.д.) и команды в `tool/verify.sh` написаны под структуру из официального Compass app. Если структура Klara отличается, их нужно поправить один раз под реальный проект.
