# Навигация

- go_router с типизированными маршрутами (`go_router_builder`). Строковые пути и `Navigator.push` в виджетах запрещены.
- Каждый маршрут имеет тип представления из общей фабрики страниц на `CustomTransitionPage`:
  - `AppPage.screen` — переход «вперёд/назад», свайп от края;
  - `AppPage.sheet` — выезд снизу, закрытие свайпом вниз и тапом по фону, без кнопок закрытия;
  - `AppPage.dialog` — только для подтверждений.
- Анимации переходов — только из фабрики. Прямая и обратная анимации одинаковые.
- Во время перехода навигация заблокирована: повторный вызов игнорируется.
- Данные следующего экрана начинают грузиться до перехода; экран открывается сразу со skeleton.
- После `await` — `if (!context.mounted) return;`.
- Каждый экран, на который ведут ссылки-приглашения, пуши или возврат из банковской авторизации, доступен по deep link и покрыт тестом маршрута.
