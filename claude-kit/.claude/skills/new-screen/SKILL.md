# Новый экран

## Перед кодом
1. Если задача пришла текстом — оформи её по шаблону `.claude/templates/feature.md` и покажи пользователю. Критерии приёмки должны проверяться командой.
2. Если есть макет — получи его через Figma MCP: размеры, токены, состояния.
3. Найди в `lib/ui/core/ui/` компоненты, которые понадобятся. Если чего-то не хватает — сначала расширь существующий компонент.

## Структура
```
lib/ui/<feature>/
  bloc/<feature>_bloc.dart     — события, sealed-состояния Initial / Loading / Success / Failure
  widgets/<feature>_screen.dart — экран на AppScaffold
  widgets/...                   — части экрана, только для этой фичи
lib/data/repositories/<feature>_repository.dart — если нужны данные; кэш здесь
test/ui/<feature>/              — Bloc-тесты, widget-тесты, golden-тесты
```

## Обязательно
- Маршрут — типизированный, тип представления `screen`, `sheet` или `dialog`. Анимации и способы закрытия берутся из фабрики страниц, свои не пишутся.
- Bloc загружает данные при создании. Действия с переходом или запросом — `droppable()`.
- Все строки — в ARB, сразу на всех языках проекта.
- Golden-тесты на каждое состояние экрана на матрице устройств из `CLAUDE.md`.
- После `await` — `context.mounted`.

## Готово, когда
- `tool/verify.sh` зелёный.
- Скилл `ui-review` пройден без замечаний.
- Каждый критерий приёмки из фича-задания подтверждён тестом.
