# Проверка экрана

Чек-лист собран из 54 дефектов, найденных в Klara. Пройди каждый пункт для изменённого экрана. Где возможно — проверяй тестом, не глазами.

## Раскладка и устройства
- [ ] Экран на `AppScaffold`; своего `SafeArea` на экране нет. (#44, #39)
- [ ] Нижняя кнопка не прилипает к краю на iPhone SE, где нижний inset равен 0. (#44)
- [ ] Фон доходит до краёв без зазоров. (#39)
- [ ] Контент, который может не поместиться, прокручивается. (#48, #52)
- [ ] Тексты не перекрывают друг друга на 375×667 и 360×640. (#2, #7)
- [ ] Текст в фигурах не выходит за границы на самой длинной локали. (#37)
- [ ] Golden-тесты на матрице устройств из `CLAUDE.md` обновлены и проходят.

## Цвет и контраст
- [ ] Все цвета — из `ColorScheme` или `ThemeExtension`, HEX нет. (#46)
- [ ] Иконка и текст кнопки берут цвет из одного `foregroundColor`. (#51)
- [ ] Контраст текста не ниже 4.5:1, иконок — не ниже 3:1; есть тест `meetsGuideline(textContrastGuideline)`. (#25, #40)
- [ ] Активная кнопка не выглядит неактивной. (#26)
- [ ] Экран корректно перекрашивается при смене системной темы. (#46)

## Навигация и sheets
- [ ] Sheet закрывается свайпом вниз и тапом по фону; других кнопок закрытия нет. (#23, #31, #33)
- [ ] Статичный контент sheet не прокручивается с пружиной. (#23)
- [ ] Повторный быстрый тап не открывает экран дважды. (#28)
- [ ] Заголовок экрана описывает действие пользователя. (#29)

## Анимации и отклик
- [ ] У каждого появления есть обратная анимация скрытия. (#14, #21, #22)
- [ ] Раскрытие блока не сдвигает закреплённые кнопки. (#32)
- [ ] Реакция на нажатие мгновенная: оптимистичное обновление или skeleton. (#11, #34)
- [ ] Haptic-отклик вызывается через общий сервис.

## Состояния данных
- [ ] Обработаны `Loading / Success / Empty / Failure`; `null` и сырые ошибки на экран не попадают. (#45)
- [ ] Данные не перезапрашиваются при каждом переключении таба. (#38)
- [ ] Список загружается при открытии экрана, а не после действия пользователя. (#30)
- [ ] Ошибки показываются пользователю и уходят в Sentry; тихих сбоев нет. (#4)

## Тексты и компоненты
- [ ] Все строки — в ARB, на всех языках проекта. (#27)
- [ ] Текст тоста соответствует действию. (#41)
- [ ] Тосты, тумблеры, кнопки, меню — shared-компоненты из `lib/ui/core/`. (#42, #50, #54)
- [ ] Декоративные элементы не похожи на кнопки и обёрнуты в `ExcludeSemantics`. (#24)
- [ ] Иконки отражают смысл и не повторяются для разных действий. (#49)
